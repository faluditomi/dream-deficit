- [x] 3b.1 Fix Unity 6 compile errors in the clipboard plumbing: `EventCommandNames` is internal (use literal command-name consts), `DropdownMenu.MenuItem` was renamed to the top-level `DropdownMenuItem`, and match default menu actions via `DropdownMenuAction.name` (not `ToString()`, which returns the type name and silently matches nothing) (design D5)

- [x] 3b.3 Fix Layout Graph not bringing the graph into view: `FrameAll()` measured stale/degenerate bounds and no-opped, and a callback scheduled from a contextual-menu action often never ran; replaced with a synchronous `UpdateViewTransform`. Final root cause: `view.layout.size` is `NaN` before layout and `NaN <= 1f` is false, so the size fallback never fired and NaN propagated into `CalculateFrameTransform`/`UpdateViewTransform` (which silently rejects NaN) — fixed with explicit `IsFinite` checks and Unity's own `GraphView.CalculateFrameTransform` for the transform (design D3)
